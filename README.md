# IA---Grupo-03
Predicción de tipo de cimentación de edificaciones
## Objetivo general
Desarrollar un modelo de inteligencia artificial para la selección del tipo de cimentación de edificaciones, utilizando parámetros geotécnicos y estructurales conforme a los criterios de la Norma Técnica E.050 “Suelos y Cimentaciones” del Reglamento Nacional de Edificaciones del Perú
